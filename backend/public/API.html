2. REST API — Scoreboard CRUD

Create Scoreboard

POST /api/scoreboards

Request body (only uniqueIdentifier required):

{
  "uniqueIdentifier": "field-1",
  "displayName": "Memorial Field",
  "homeTeamName": "Tigers",
  "awayTeamName": "Eagles"
}

Response: 201 Created

{ "scoreboard": { ... full Scoreboard object ... } }

Errors: 400 missing/invalid identifier · 409 duplicate identifier

List Scoreboards

GET /api/scoreboards

Response: 200 OK

{ "scoreboards": [ { ... }, { ... } ] }

Get Single Scoreboard

GET /api/scoreboards/:id

Path params: id — numeric scoreboard ID (e.g. 1)

Response: 200 OK

{ "scoreboard": { ... full Scoreboard object ... } }

Errors: 404 Not found

Update Metadata

PUT /api/scoreboards/:id

Updates: uniqueIdentifier, displayName, homeTeamName, awayTeamName, gameId. Merge-patch — only included fields are updated. Does not increment stateVersion.

{
  "displayName": "Updated Name",
  "homeTeamName": "Lions",
  "gameId": "gc-12345"
}

Send "gameId": null to clear it.

Response: 200 OK → { "scoreboard": { ... } }

Errors: 400 validation · 404 not found · 409 duplicate identifier

Delete Scoreboard

DELETE /api/scoreboards/:id

Response: 200 OK

{ "deleted": true, "id": 1 }

3. REST API — State Updates

Update State

PUT /api/scoreboards/:id/state

Updates: homeScore, awayScore, inning, half, balls, strikes, outs, gameId. Merge-patch semantics. Auto-increments stateVersion. Triggers WebSocket broadcast to all subscribed clients.

{
  "homeScore": 5,
  "awayScore": 3,
  "inning": 6,
  "half": "top",
  "balls": 0,
  "strikes": 0,
  "outs": 1
}

Response: 200 OK → { "scoreboard": { ... } }

Errors: 400 validation · 404 not found

4. REST API — Display Endpoint (Bandwidth-Optimized)

Get Display State

GET /display/:identifier

Designed for electronic scoreboard hardware clients to poll. Returns the compact payload with single-letter keys. ETag/304 caching support for zero-byte responses when unchanged.

Path params: identifier — the scoreboard's uniqueIdentifier (e.g. field-1)

Response: 200 OK

{
  "h": 3, "a": 2, "i": 5, "hf": "b", "b": 2, "s": 1, "o": 1, "v": 8
}

Headers: ETag: "8" · Cache-Control: no-cache

ETag / 304 Caching

Send the If-None-Match header from the last response's ETag:

GET /display/field-1
If-None-Match: "8"

If the state version hasn't changed, the server responds with:

HTTP/1.1 304 Not Modified

No response body — zero bytes of payload. Wildcards accepted: If-None-Match: *

Errors: 404 scoreboard not found or inactive

5. WebSocket Events (Socket.io)

Connection URL: https://scoreboard.ubiconet.com (or http://localhost:4020 in dev)
Transports: websocket, polling (fallback)

Client → Server Events

EventPayloadDescription
subscribe scoreboardId: number Join a scoreboard's update room. Only receive updates for subscribed boards.
unsubscribe scoreboardId: number Leave a scoreboard's room.
state:change { scoreboardId, patch } Push a state change directly. Server persists, increments version, broadcasts to all other clients in the room. Sender excluded from echo.

state:change example:

socket.emit('state:change', {
  scoreboardId: 1,
  patch: { homeScore: 5, balls: 2, strikes: 1 }
});

The patch uses the same field names and validation rules as PUT /api/scoreboards/:id/state.

Server → Client Events

EventPayloadDescription
state:update Display State (compact) Broadcast whenever a scoreboard's state changes — via REST PUT /state or socket state:change. Same shape as display endpoint.

Recommended Client Patterns

Operator control panel (the web UI):

// 1. Connect socket
const socket = io('https://scoreboard.ubiconet.com');

// 2. Subscribe to a scoreboard
socket.emit('subscribe', 1);

// 3. Listen for state changes from other operators
socket.on('state:update', (payload) => {
  // payload = { h, a, i, hf, b, s, o, v }
  renderScoreboard(payload);
});

// 4. Push a change instantly (no REST round trip)
socket.emit('state:change', {
  scoreboardId: 1,
  patch: { homeScore: 5, inning: 6 }
});

Electronic display board (hardware):

// Option A: WebSocket (recommended — instant updates)
const socket = io('https://scoreboard.ubiconet.com');
socket.emit('subscribe', 1);
socket.on('state:update', renderScoreboard);

// Option B: Poll display endpoint with ETag (fallback)
let etag = null;
setInterval(async () => {
  const res = await fetch('https://scoreboard.ubiconet.com/display/field-1', {
    headers: etag ? { 'If-None-Match': etag } : {}
  });
  if (res.status === 304) return;        // unchanged — keep current state
  etag = res.headers.get('ETag');
  const state = await res.json();
  renderScoreboard(state);
}, 5000);
